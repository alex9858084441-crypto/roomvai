## 1. Описание сервиса

RoomVAI — Приложение, которое позволяет:
- Сфотографировать помещение (2–4 ракурса) и выбрать дизайнерский стиль.
- Сгенерировать варианты интерьера с помощью нейросети (ControlNet + Stable Diffusion).
- Сравнить оригинал с результатами, сохранить изображения, поделиться ими.
- Просматривать историю генераций.

Приложение предоставляет 1 бесплатную генерацию после регистрации. Дальнейшее использование требует подписки RoomVAI Pro.
